## 1. 目标与边界（已澄清）

| 项 | 结论 |
|---|---|
| 定位 | 高频/任意频率**注入基础设施**——一次投入，多方复用 |
| 声学回报（蜂鸣器） | **实打实的功能**：可用声音回报诊断信息（上电鸣叫等）。其基波生成与常规注入**同源**（同一 L3 通用查表三角函数），共用同一条基波生成路径 → 纳入本计划 |
| 音乐播放 | **另一条路**：需显式存储音符表，基波生成方式（查表格式）与常规注入完全不同 → **本轮不做，独立路线** |
| 位置检测（HFI） | 当前电机为**表贴式（SPM）**，经典电压注入 HFI 原理上不可用；框架需为将来 IPM/其他电机预留解调接口，算法不在本轮 |
| 硬收益 | **参数辨识 R、L**（NEXT_MISSION 第 2 条）、运放增益平衡、注入响应观测、声学回报（蜂鸣器） |
| 不做限制 | 注入启用时**不**对电流环 kd 等参数做编译期约束（由用户自行配置） |

## 2. 现状事实（调研结论，均为代码实测）

### 2.1 时序与数据流

| 项 | 值 / 位置 |
|---|---|
| PWM 载波 | `FOC_PWM_FREQ_KHZ` = 24 kHz |
| 电流环 | 3ISR 独立定时器 8 kHz（`FOC_CURRENT_LOOP_ISR_FREQ_HZ`）；或 2ISR 分频 = PWM / `FOC_CURRENT_LOOP_ISR_DIVIDER` |
| 控制 ISR | 1 kHz（唯一 `iq_target` 生产者，经 `ctrl_ref` 单点原子发布） |
| 电流采样 | ADC 由 PWM 同步触发 24 kHz；电流环读取时**平台侧对最近 N 次采样平均**（N = `FOC_CURRENT_LOOP_ADC_AVG_COUNT`，当前 3） |
| SVPWM 插值 | `FOC_SVPWM_INTERP_ENABLE`（当前 DISABLE）；启用时 `interp_steps_total = FOC_PWM_FREQ_KHZ`（24 步 ≈ 1 ms） |
| SMO 运行率 | 电流环率（8 kHz），dt 取 `FOC_CURRENT_LOOP_DT_SEC` |
| UART | 115200 bps（USART0/2） |

### 2.2 现有链条与缺口

```
控制 ISR: 外环/开环 → iq_target → ctrl_ref 单点发布
电流环 ISR: 采样 → Clarke(ialpha/ibeta) → Estimator(SMO/HFI) → SourceMgr
            → 电流环PID → ctrl.ud/uq → 逆Park → alpha_beta → SVPWM → duty → 平台
```

- **注入环节完全不存在**：`ctrl.ud/uq` 与逆 Park 之间没有任何叠加点。
- **HFI 为空壳**：`foc_estim_hfi_state_t` 仅两个解调字段，`FOC_EstimHFI_Step` 为 no-op；`FOC_SOURCE_TYPE_HFI` 在 SourceMgr 中硬编码返回 `LOCKED`（占位）。
- **可复用的旁路入口**：`SVPWM_ApplyDirectDuty`（直写 duty）、`FOC_PHASE_OUTPUT_DIRECT_DUTY`（特殊 phase 输出类型）。
- **不可复用**：`FOC_PHASE_OUTPUT_*` / `control_phase` 由**控制 ISR（1 kHz）**推进，更新率过低；`fifo_queue_t` 深度上限 255、元素 uint16_t，不适合音频缓冲。

### 2.3 三个会决定成败的隐藏约束（本轮新发现）

**(a) 电流反馈链已含平均滤波**
平台对最近 3 个 PWM 采样求平均后才交给电流环 → 等效 3 抽头移动平均（24 kHz 上的低通）。解调可用频段：DC~3 kHz 良好，> 4 kHz 迅速衰减，8 kHz 处为零点。

**(b) SVPWM 插值会"杀死"注入**
插值启用时 `interp_steps_total` = 24（≈1 ms），而电流环每 3 个 PWM 周期才写一次新目标 → 每个电流环周期内只推进 3/24 = 1/8 的差值步长。结果：注入波形**幅值被压缩约 8 倍、相位严重滞后**，注入不可用。

**(c) 过调制限幅会等比缩放"基波 + 注入"**
`FOC_ControlApplyElectricalAngleCore` 计算 `dq_magnitude` 并按 `voltage_limit` 等比缩放 `ud/uq`。注入抬高幅值 → 高调制比工况下注入被压缩甚至消失（而该工况恰是低速大转矩、最需要注入时）。

### 2.4 注入影响 SMO 的量化参数（当前配置）

| 参数 | 值 | 对注入的含义 |
|---|---|---|
| `FOC_ESTIM_SMO_SAT_CURRENT_A` | 0.10 A | 注入引起的电流估计误差远小于此值时，滑模饱和函数工作于近似线性区 → 无互调 |
| `FOC_ESTIM_SMO_BEMF_LPF_FC` | 2000 Hz | 1 kHz 注入仅衰减 ~1 dB（**抑制不足，需评估**）；2 kHz→3 dB；4 kHz→6.8 dB |
| `FOC_ESTIM_SMO_SPEED_LPF_FC` | 100 Hz | 注入引起的速度抖动被强烈抑制 ✅ |
| `FOC_ESTIM_SMO_PLL_KP / KI` | 140 / 450 | PLL 环路带宽远低于注入频率 → 角度抖动被抑制 ✅ |
| `FOC_ESTIM_SMO_K_SLIDE` | 0.75 | BEMF 估计增益（注入经此通道进入 bemf） |

**张力**：注入幅度要足够大才有解调信噪比，但不能把滑模误差推进饱和区（否则出现非线性互调）。

## 3. 设计原则（对应 5 点澄清）

1. **ISR / 插值架构必须显式适配**：注入执行位置与 2ISR/3ISR × 插值启用/禁用 四种组合都要给出行为定义，不假设单一架构。
2. **相干模式与任意频率模式是两种对等模式**，用宏**显式互斥切换**（非"主辅"关系），各自有独立的相位机制与解调路径。
3. **不人为剥离注入去"保护" SMO**：注入是电机真实动态的一部分，应显式进入 SMO 过程；本轮以**量化评估**（§5.5 三个比值）代替强制隔离，"基波电压分离"仅作评估不达标时的备选缓解。
4. **注入轴参数化 + 宏裁剪**：同一套函数同时支持 d / q / 双轴，运行时用传参决定施加轴，编译期用宏裁剪可用轴与通道。
5. **不做参数限制**：不对电流环 kd / 环路增益施加编译期约束。

## 4. 注入点定位（结论）

| 通道 | 施加位置 | 谁执行注入 | 频率上限 | 相位确定性 | 用途 |
|---|---|---|---|---|---|
| **CH_DQ_VOLTAGE（本轮实现）** | `ctrl.ud/uq` 叠加，位于**电流环 PID 输出之后、逆 Park 之前** | 逆变器直接施加 | 采样/开关频率量级 | 好（不受 PID 动态调制） | HFI、参数辨识、运放增益平衡 |
| CH_IQ_TARGET（阶段 4） | `iq_target` 物化后叠加 | 电流环 PID 跟随 | 电流环带宽（约数百 Hz） | 差 | 声学回报（蜂鸣器级） |
| CH_DUTY（明确不做） | 逆 Park 后 / 直写 duty | 旁路闭环 | 最高 | 好 | 完整音频（后续另论） |

**为什么不走"电流参考注入"让 PID 去调**：注入频率会被电流环带宽吃掉（HFI 需 1~2 kHz，环路可用带宽仅数百 Hz），且穿过 PID 后相位随增益/饱和漂移，解调失准。

## 5. 框架设计

### 5.1 三层抽象

```
注入源 Source
  ├── COHERENT : 相干频率族（f_inj = 电流环率 / N，N 为整数）→ 相位按步进固定
  └── ARBITRARY: 任意频率（相位累加器 NCO + 查表）
        │
注入通道 Channel（轴参数化：D / Q / DQ，宏裁剪）
  └── CH_DQ_VOLTAGE: ctrl.ud/uq += inj
        │
消费方 Consumer
  ├── 声音（无需解调，阶段 4）
  └── 解调器（幅值/相位提取 → R/L 辨识；位置误差 → PLL，后续）
```

### 5.2 相干 / 任意频率模式的选择依据（核心议题）

两种模式**不是主辅关系**，而是针对不同"误差等级"的两条实现路径；选择依据必须量化，且与宏给定的注入环频率强耦合，不能一句话概括。

#### 5.2.1 两种模式的误差机制完全不同

| 模式 | 频率精度 | 解调实现 | 主要误差源 |
|---|---|---|---|
| `FOC_INJECTION_MODE_COHERENT` | **被量化到离散频点** f_环/N | 相位分箱累加（无需乘法器） | ①频率量化误差 ②相位箱数不足 |
| `FOC_INJECTION_MODE_ARBITRARY` | 连续（NCO 相位累加器精度） | 正交解调 + 低通 | ③积分窗口非整数周期 → 频谱泄漏 ④与 f_环 的低阶差拍落入解调低通 |

#### 5.2.2 误差源①——相干模式的频率量化误差（与注入环频率强相关）

相干频点为 f_环/N，相邻频点相对间隔约 1/N。**注入环频率越低、目标频率越高，量化越粗**：

| 目标 f_inj | f_环 = 8 kHz（3ISR 或 2ISR÷3） | f_环 = 24 kHz（2ISR÷1） |
|---|---|---|
| 4 kHz | N=2，误差 0 | N=6，误差 0 |
| 3 kHz | N=3 → 2667 Hz，**误差 11%** | N=8，误差 0 |
| 2 kHz | N=4，误差 0 | N=12，误差 0 |
| 1.5 kHz | N=5 → 1600 Hz，误差 6.7% | N=16，误差 0 |
| 1 kHz | N=8，误差 0 | N=24，误差 0 |
| 750 Hz | N=11 → 727 Hz，误差 3.0% | N=32，误差 0 |
| ≤500 Hz | N≥16，误差 ≤3% | 误差 ≤1.5% |

**结论**：低 f_环 + 高频注入时量化误差可达 10~33%，会直接传导进"基于频率的物理量计算"（如 L = V/(2πf·I)）——**这正是"高频必须相干"的量化依据**；而低频段 N 大、步长按 f_环/N² 递减，量化误差小到可接受，故低频不强制相干。

#### 5.2.3 误差源②——相干模式的相位箱数不足

相干解调的相位分辨率为 360°/N：

| 注入频率 | f_环 = 8 kHz | f_环 = 24 kHz |
|---|---|---|
| 2 kHz | N=4 → 90° 步进（**不可用**） | N=12 → 30° |
| 1 kHz | N=8 → 45° | N=24 → 15° ✅ |
| 500 Hz | N=16 → 22.5° | N=48 → 7.5° ✅ |

即"必须相干"**不等于**"相干一定可行"：高注入频率 + 低 f_环 时，相干解调本身也退化，需满足 N ≥ N_min（默认 8，可配置），否则该频点应被拒绝或改走任意频率模式。

#### 5.2.4 误差源③④——任意频率模式的泄漏与差拍

- **频谱泄漏**（幅度相对误差量级）≈ 1/(2π·f_inj·T_int)：f_inj=1 kHz、T_int=10 ms → 约 1.6%；T_int=100 ms → 约 0.16%。相干模式取整数个注入周期，泄漏为 0。
- **差拍**：f_inj 与 f_环 的低阶分频接近时，差拍分量落入解调低通通带 → 解调输出出现低频纹波或漂移。

即：任意频率模式以"更长的积分时间 + 更复杂的解调"换取频率连续可调。

#### 5.2.5 决策准则（AUTO：按误差等级选择）

给定 (f_环, f_tgt)：

1. **源头上限幅**：目标频率先收敛到 `[f_环/N_max, f_环/N_min]`（越界 / 非正 / NaN 一并归入边界）——限幅后分频比 `N = round(f_环/f)` 必然落在 `[N_min, N_max]`，除零与越界不可能出现；
2. 计算最近相干频点 `f_环/N` 及其相对误差 `e_coh`；
3. 若 `e_coh ≤ 阈值`（可配置）→ **COHERENT**（零泄漏、解调最简、算力最低）；
4. 否则 → **ARBITRARY**（频率连续，代价是更长积分）；
5. **相位箱数下限**：COHERENT 需 `N ≥ N_min`（当前 4，可配置），由第 1 步的限幅直接保证；
6. **上报实际生效频率 `f_act`**：消费方（R/L 计算）必须使用 `f_act` 而非 `f_tgt`，使量化误差不进入最终结果——量化误差只影响"选频意图"（避开 SMO 的 BEMF 低通、避开机械共振）。
7. **不做"拒绝该频点并上报"**（v2.4.x 优化轮修订）：注入是**被动工具、无上报通道**，非法频点在**数据产生点**被限幅收敛，`f_act` 即唯一回报口径。上述 2~4 步的判定仅在 `BOTH_AUTO` 档生效；`COHERENT_ONLY` / `ARBITRARY_ONLY` 由编译期宏直接决定模式。

> 这是"按误差等级确定"的落地形式：宏给定 f_环 → 运行时按准则在两种模式间选择，而非在配置里写死某一种。

#### 5.2.6 与宏的耦合（为什么策略不能写死）

注入环频率 f_环 由以下宏共同决定，进而决定可用频点集合、量化误差、相位箱数，以及电流平均滤波带来的注入上限：

| 宏 | 对注入策略的影响 |
|---|---|
| `FOC_CURRENT_LOOP_ISR_MODE`（2ISR/3ISR） | 决定 f_环 的来源与注入执行上下文 |
| `FOC_CURRENT_LOOP_ISR_DIVIDER`（2ISR） | f_环 = PWM ÷ 分频 → 直接决定上表结果 |
| `FOC_CURRENT_LOOP_ISR_FREQ_HZ`（3ISR） | f_环 独立可配 → 可专门为注入提高 f_环 |
| `FOC_PWM_FREQ_KHZ` | 上限约束与 2ISR 分频基数 |
| `FOC_SVPWM_INTERP_ENABLE` | 是否需要在注入期间旁路插值（§5.3） |
| `FOC_CURRENT_LOOP_ADC_AVG_COUNT`（派生） | 电流平均滤波强度 → 解调可用频段上限（§2.3a） |

**结论**：注入模式的选择是"宏组合 × 目标频率"的联合决策，因此实现上必须保留运行时判定 + 上报，而不能仅靠编译期二选一；编译期宏只负责**裁剪**（是否需要 COHERENT 实现、是否需要 ARBITRARY 实现），运行时负责**选择**。



### 5.3 执行位置与 ISR 架构适配（对应澄清第 1 点）

注入本轮统一执行于**电流环核心过程**：`FOC_CurrentControlStep` **之后**、`FOC_ControlApplyElectricalAngleRuntime` **之前**（即 executor 阶段 4b；同一函数内随后完成同拍解调累加）。

| 架构组合 | 注入写入路径 | duty 生效路径 | 对注入的影响 / 处理 |
|---|---|---|---|
| 2ISR + 插值禁用 | 电流环 ISR 内直接叠加 | 同 ISR 内 `SVPWM_Update` 直写 duty | ✅ 无附加环节，注入带宽 = 电流环率/2 |
| 2ISR + 插值启用 | 同上 | `SetRuntimeDutyTarget`（24 步内逼近） | ⚠️ 被插值压缩（§2.3b）→ 注入激活时旁路插值 |
| 3ISR + 插值禁用 | 电流环 ISR 内叠加 | pending 目标 → PWM ISR 直写 | ✅ 干净（唯一差异是跨 ISR 提交） |
| 3ISR + 插值启用 | 同上 | pending 目标 → PWM ISR 插值推进 | ⚠️ 同上，必须旁路 |

**处理策略**：
- **主策略（运行时）**：注入启用（`injection_state.enabled != 0`）期间执行输出改走 `FOC_ControlApplyElectricalAngleDirect`（`direct_output = 1`，`SVPWM_ApplyDirectDuty` 直写占空比），由 executor 阶段 5 直接判定；注入停止后恢复原插值行为。
- **可选编译期加固**：若某实例确定不启用插值，可用编译期约束收紧（默认不强制，因为"注入期间旁路"已足够）。
- **后续优化项（本轮不做，记录备查）**：让 `interp_steps_total` 与电流环分频对齐（而非 PWM 频率），使插值在电流环周期内完成，从而允许注入与插值共存且无需旁路。该改动会改变既有插值平滑特性，需独立评估。

**相干采样条件**：相干模式的 N 对齐**电流环率**（而非 PWM 频率）——解调在电流环率上进行，采样平均也以电流环周期为单位。

### 5.4 与过调制限幅的关系（应对 §2.3c）

注入叠加会抬高 `dq_magnitude`，可能触发既有的等比缩放（`voltage_limit` 限幅）。**不引入电压预算分配机制**：由既有过调制限幅自然处理，注入分量随整体一同衰减；该状态可通过示波器对照注入波形与 duty / `iq` 观测。保持实现精简，不为注入增加专用预算逻辑与回写字段。

### 5.5 与 SMO 的相互作用（对应澄清第 3 点）

**不隔离，显式进入**：注入电压经 `alpha_beta` 进入 `EstimSMO_StepCore` 的 `u_alpha/u_beta`；注入电流进入 `ctrl.ialpha/ibeta`。数学上二者都是电机真实动态，观测器本就应处理。

需评估的三个比值（写入验证项）：

| 比值 | 当前配置下的情形 | 判据 |
|---|---|---|
| 注入电流峰值 / `FOC_ESTIM_SMO_SAT_CURRENT_A` | 饱和限幅 0.10 A | 建议 ≤ 0.2（保持滑模近似线性，避免互调与 BEMF 谐波） |
| `f_inj` / `FOC_ESTIM_SMO_BEMF_LPF_FC`（2 kHz） | 1 kHz 注入仅 −1 dB | 若注入落入该 LPF 通带，bemf 会出现注入频率纹波 → 实机观察 `converged` / `lost_count` 与角度抖动 |
| `f_inj` / `FOC_ESTIM_SMO_SPEED_LPF_FC`（100 Hz）、PLL 带宽 | 差 1~2 个数量级 ✅ | 速度与角度通道天然抑制 |

**冲突窗口**：注入频率越高（利于避开 SMO 的 BEMF 低通）越会撞上 §2.3a 的电流平均滤波（≤ ~3 kHz），可选频段窗口较窄。若实机评估不达标，备选缓解是"向 SMO 提供注入叠加前的基波电压"（即此前提到的分离方案），但**需先与你确认**再实施。

### 5.6 与其他机制的边界

| 机制 | 关系 |
|---|---|
| 软切换 `blend_factor` | 注入叠加在软切换混合结果之后，独立于软切换状态 |
| 特殊 phase（COGGING_CALIB / REINIT） | 走 `phase_output` 旁路、不经电流环核心 → **注入自动不生效**（本轮接受该语义并在文档标注） |
| 源切换 PID 无扰预置 | 无交互（预置发生在切换瞬间，注入是稳态激励） |
| `ctrl_ref` 单点发布 | 阶段 1 注入**不触碰 `iq_target`** → **不需要任何写者仲裁改动** ✅（阶段 4 声学回报通道才需定义所有权让出，采用"电流环 ISR 物化后单点覆盖"，仍不改发布协议） |

### 5.7 观测通道（示波器）

需求：显示**即将注入的波形**（注入分量本身，而非注入后的 `ud/uq`）。

现状：`FOC_OSC_CHANNEL_COUNT` = 16，掩码 `oscilloscope_param_mask` 为 16 位，**通道已满**。但 bit9（`current_a_raw`）与 bit10（`current_b_raw`）在协议文档中已声明，而代码中 `snapshot.channel[9]/[10]` **恒为 0**（源码注释标注 `bit 9, 10 unused`）→ 属"已声明但未实现"的闲置位。

| 方案 | 做法 | 成本 / 风险 |
|---|---|---|
| **A（推荐）** | 复用闲置位：bit9 → `injection_wave`（即将注入的波形），bit10 → `injection_demod`（阶段 2 解调结果） | 通道数与帧格式**不变**；只需重定义两个掩码位语义并同步文档与上位机（历史该两位恒为 0，兼容风险低） |
| B | 扩展 `FOC_OSC_CHANNEL_COUNT` 16→17、`DEBUG_STREAM_OSC_PAYLOAD_LEN` 80→85 | 帧格式 breaking 变更，上位机必须同步 → 本轮不做 |

**观测口径（复用既有电压基准语义，不新增配置项）**：

通道输出为**即将注入的电压分量（V）**（叠加前的注入量）。其"设置电压 / 实际电压"口径直接沿用 `FOC_CURRENT_LOOP_VOLTAGE_BASE_SOURCE`——注入分量与整条电压计算链处于同一口径，无需为观测通道引入独立配置。轴：按注入轴取主轴分量（D→d 分量，Q→q 分量，DQ→合成幅值）。

**方案 A 改动点**：
- `foc_symbol_defs.h`：两个掩码位重命名（`..._PARAM_INJECTION_WAVE` / `..._PARAM_INJECTION_DEMOD`）
- `foc_cfg_init_values.h`：对应默认掩码开关项重命名
- `foc_compile_limits.h`：默认掩码组合宏同步
- `foc_debug_stream.c`：`snapshot.channel[9]/[10]` 从注入状态读取（与注入同源、同拍）
- `docs/protocol-parameters.md`：§4.6 掩码位表与说明同步
- 上位机：掩码位语义更新（该两位历史恒为 0）

## 7. 分阶段执行步骤

每阶段独立可验证、可裁剪、可回退；每步末尾必须编译验证（0 error、不新增 warning）并同步构建入口。

**阶段顺序（已调整）**：`1 注入 → 2 解调 → 4 声学回报 → 3 参数辨识 R/L`。交换 3/4 的理由：音频回报是**更易实机验证**的现象（示波器采样率不足以观测注入波形，R/L 与万用表 / LCR 的对照条件受限）。注入为被动工具，其波形验证由阶段 2 的解调流程驱动，**不引入临时代码**。

### 阶段 1：注入基础设施（CH_DQ_VOLTAGE + 两种模式 + AUTO 判定）

> 范围：**一次完整实现**（两种模式 + BOTH_AUTO 运行时判定 + 观测通道 + 复位），不做分次裁剪。

1. **LS 层**：类型文件 + 总开关 + 模式三选一宏 + 轴裁剪 + 默认值（含 `N_min`、量化误差阈值）+ 编译期校验；示波器掩码位 bit9/bit10 重定义（§5.7）。
2. **L3 层**：**不新增波形模块**——单位正弦直接复用通用查表 `FOC_MathLut_SinCos`（`L3_Hal/foc_math_lut.h`，全项目唯一三角函数来源）；两种模式的差异只在相位生成：相干 = 固定步进 `2π/N`，任意频率 = 相位累加。
3. **L2 层**：`foc_ctrl_injection` —— 状态（enable / axis / mode / freq）+ **配置期输入收敛（轴掩码 + 幅值/频率限幅）与 AUTO 模式选择（§5.2.5）** + 派生量缓存（每拍相位增量、解调窗口/归一化与 LPF 系数、延迟补偿旋转量）+ `freq_act` 上报；ISR 只做"推进 + 生成 + 叠加 + 同拍解调累加"，执行器按 `enabled` 判定旁路插值（**不引入电压预算**，见 §5.4）。
4. **接入点**：executor 阶段 4b 调用；`foc_ctrl_actuation` **无需改动**（阶段 5 改调既有的 `FOC_ControlApplyElectricalAngleDirect` 直写占空比）；`FullStop` / `RebuildControlBasis` 复位注入状态。
5. **观测**：示波器 bit9 = `injection_wave`（即将注入的波形）。
6. **验证**：
   - 示波器观察：注入波形频率/幅值/轴与设定一致，`freq_act` 与目标频率的偏差符合 §5.2 预期；
   - 频点收敛：对越界目标频率验证限幅结果（`freq_act` 必落在 `[f_环/N_max, f_环/N_min]`）与 `BOTH_AUTO` 选模结果符合 §5.2.5 准则；
   - 2ISR/3ISR × 插值启用/禁用 四种组合各测一次，确认 §5.3 行为定义与"旁路插值"生效；
   - 复位验证：`S:M=0` 禁能、`Y:C` 复位后注入状态归零；
   - 注入关闭时既有有感/无感控制零回归（ROM 与行为不退化）。

**实施状态：已完成（编译验证）**

| 项 | 实测 |
|---|---|
| 默认档（`ENABLE` + `BOTH_AUTO`，两轴启用） | 0 error / 0 warning，ROM **57.23 KB（58600 B）**、RAM 7.43 KB |
| `FOC_INJECTION_ENABLE = DISABLE` | 0 error / 0 warning，ROM **52.58 KB（53844 B）** = v2.4.1 基线 53768 B + 76 B（电流环发布 `id_measured`）⇒ 注入自身零残留 |
| 两轴全关 | 按预期触发编译期 `#error`（`foc_compile_limits.h`） |
| 未启用时行为 | 与 v2.4.1 一致：阶段 4b 无副作用，阶段 5 仍走 `...Runtime` 原路径 |

> `MODE` 三档与轴掩码是**能力集合裁剪**（编译期常量），其一致性由 `foc_compile_limits.h` 校验保证，不再逐档列为编译验证矩阵。

**ISR 快线（反汇编核实）**：`FOC_ControlInjectionStep` 47 条指令，内含 2 次调用——通用查表 `FOC_MathLut_SinCos` 与同拍解调累加 `Injection_DemodAccumulate`（64 条）；**无浮点除法、无变长回卷循环、无 `Math_WrapRad` / `Math_NormalizeDt` 调用、无合法性判定**；派生量（`phase_inc_rad`、解调窗口长度与归一化系数、I/Q 与幅值 LPF 系数、延迟补偿旋转量）在 `Init` / `Configure` 一次算好，含 `sqrtf` 的结算 `Injection_DemodSettle` 每窗口一次、不在每拍路径。

**优化轮修订的三处语义（与本节早期草案的差异）**：
1. **限幅替代"拒绝并上报"**：`Configure` 无返回值、状态体无 `status`；越界/非正/NaN 频率、负幅值、轴越界一律在配置期收敛，`freq_act` 为唯一回报口径。
2. **注入速率锚定电流环率**：`Step` 不再接收 `dt`（唯一调用点本就恒定传 `FOC_CURRENT_LOOP_DT_SEC`）⇒ 相位增量有界（`N_MIN ≥ 2` 编译期约束）⇒ 单次条件回卷成立。
3. **指针契约收窄**：状态指针来源为 `motor` 内嵌地址，构造上非 NULL，模块内不设空指针检查；`.clinerules` 指针校验规则同步修订为"只在指针可能为 NULL 时检查"。

**实施收敛（优化轮）**：注入与解调的单位正弦**直接复用 L3 通用查表三角函数** `FOC_MathLut_SinCos`（`L3_Hal/foc_math_lut.h`，与电流环 Park、执行器逆 Park、SMO PLL 同源），删除模块内曾用于波形生成的自带 64 点 Q15 小表 + 线性插值——三角函数全项目只有一处实现，注入不再持有平行表。

### 阶段 2：解调器（不含位置语义）—— 实施顺序第 2 步

原计划：

1. L3 解调器：按实际生效模式选择——COHERENT 走相位分箱累加，ARBITRARY 走正交解调 + 低通。（**实现收敛**：解调并入 L2 `foc_ctrl_injection`，不单列 L3 模块；COHERENT 为整周期相关累加，ARBITRARY 为正交解调 + I/Q 低通。）
2. 上报：解调结果经示波器 bit10 = `injection_demod` 输出（§5.7 方案 A）。
3. 验证：不同注入幅值/频率下的解调线性度与相位一致性；评估 §5.5 三个比值，尤其在 SMO 收敛状态下观察 `converged` / `lost_count`、角度抖动、`bemf` 纹波。

**实施状态：已完成（编译验证）；实机验证并入阶段 4 之后**

| 项 | 结论 |
|---|---|
| 归属 | 解调并入 `foc_ctrl_injection`（不新增模块/文件）：状态为 `foc_injection_state_t.demod` 子结构体；**无独立裁剪宏**，随 `FOC_INJECTION_ENABLE` 一同编译；配置由注入的 `Configure` 单点完成 |
| 参考相位 | 解调参考取注入本拍 `FOC_MathLut_SinCos` 的同一次结果（与施加电压严格同相）⇒ 解调**零新增三角函数表** |
| 输入 | `ctrl.id_measured`（新增，由电流环 Park 单点发布、与 `iq_measured` 语义镜像）+ `ctrl.iq_measured` |
| 相干模式 | 整周期（N 拍）相关累加，归一化 2/N，零泄漏、无 LPF；每周期结算一次 |
| 任意频率模式 | I/Q 一阶低通（截止 = f_inj/K）+ 每 `SETTLE_DIV` 拍结算 |
| 结算成本 | 仅 `sqrtf`（硬浮点）；**不在 ISR 引入 atan2**（相位由 I/Q 交消费方/上位机）；含"激励→采样 1 拍延迟"的精确旋转补偿 |
| 观测 | bit10 → `injection_demod`（主轴响应幅值 [A]）；语义流在注入启用时 10→13 行（`injection.demod_magnitude_a` / `_in_phase_a` / `_quadrature_a`，未激活时三行上报 0；注入特性被宏裁剪时整行跳过并回落 10 行，帧尾空白行随末行迁移） |
| 编译验证 | 默认档 0 error / 0 warning、ROM 57.23 KB（58600 B）/ RAM 7.43 KB；`FOC_INJECTION_ENABLE = DISABLE` 0 error / 0 warning、ROM 52.58 KB（53844 B，相对 v2.4.1 基线 +76 B：电流环额外发布 `id_measured`，不做"注入感知"条件编译以保持电流环不依赖注入特性） |
| 控制面 | **本轮不做**（决策：高频注入当前是自驱动闭环行为、缺少可靠测试手段；阶段 4 声学回报完成后可外部显式驱动电机，更早获得可靠验证） |
| 待实机验证 | 解调线性度（幅值 ↔ 注入幅值/频率）、I/Q 相位与 RL 模型一致性、1 拍延迟补偿残差标定；§5.5 三个比值（SMO 互调/纹波） |

**物理边界（阶段 3 前置认知）**：电流环闭环时 PID 会部分抵消注入（频率越低越明显），解调得到的是**闭环残差响应**；R/L 辨识需在环路带宽外选频或临时降低环路增益——该策略属辨识流程，不进工具层。

### 阶段 3：参数辨识 R、L —— 实施顺序第 4 步

1. 由解调幅相计算 R、L（低频注入测 R，较高频注入测 L），含运放增益平衡对比。
2. 辨识流程 + 结果上报 + 与万用表/LCR 对照。
3. 验证：辨识值稳定性、重复性、不同注入频率下的一致性。

### 阶段 4：声学回报（CH_IQ_TARGET，蜂鸣器级）—— 实施顺序第 3 步

1. 新增 `iq_target` 通道；所有权语义采用"电流环 ISR 物化后单点覆盖"，**不改动 `ctrl_ref` 协议**。
2. 由内部状态机按事件触发鸣叫，与常规注入**共用同一条基波生成路径**（仅频率/幅值/时长不同）；含包络（防爆音）与幅值限幅。
3. 引入"诊断鸣叫码表"（事件 → 频率/节奏），供上电自检、fault 回报等场景使用。
4. 验证：实机听音、温升、噪声、对控制的影响（仅允许状态使用）。
5. **音乐播放不在本阶段**：其基波生成走显式音符表，与本节发生器无关，属独立路线。

### 阶段 5（后续另论，不在本计划内）

完整音频（控制停用 + 串口解调）、INFORM / 旋转注入用于 SPM 位置检测、`interp_steps_total` 与电流环分频对齐。

| 电流反馈 3 点平均的低通（§2.3a） | 高频解调幅值失真 | 注入频率上限受限于 ~3 kHz；解调按实际频响补偿或标定 |
| 过调制缩放削弱注入（§2.3c） | 高调制比下注入失效 | §5.4 电压预算，并上报"被缩放"状态供调参 |
| 注入进入 SMO 的 BEMF 通道（LPF 2 kHz 抑制不足） | `converged`/`lost_count` 抖动、角度纹波 | 选频 + 控制注入幅度；实机评估；备选"基波电压分离"（需确认） |
| 滑模饱和非线性引入互调 | BEMF 谐波 → 角度误差 | 注入电流幅值远小于 `SAT_CURRENT`（建议 ≤ 20%） |
| 注入额外电流/发热 | 温升、噪声、机械应力 | 幅值限幅 + 启用时限 + 实机温升观测 |
| 相干模式频率被量化 | "任意频率"不成立 | 由宏切换到 ARBITRARY 模式（两模式对等，非主辅） |
| 新增字段/文件影响既有构建 | 链接错误、ROM 增长 | 宏全裁剪 + 构建入口同步 + 每步编译验证 |

## 9. 决策记录

> 本节为最终确认的决策，实施以此为准。

| 议题 | 结论 |
|---|---|
| 注入模式 | 相干 / 任意频率为两条**对等**路径；宏三选一（`..._COHERENT_ONLY` / `..._ARBITRARY_ONLY` / `..._BOTH_AUTO`）；**阶段 1 一次完整实现**（含 BOTH_AUTO 的运行时判定，不做分次裁剪） |
| 协议入口 | **不加**。注入是**被动工具**：由调用方模块（辨识流程 / 声学回报 / 未来 HFI）通过 API 配置与启停，注入模块自身不决定"何时注入" |
| 复位 | 纳入 `FullStop` / `RebuildControlBasis` |
| 观测通道 | 示波器复用闲置位 bit9/bit10（§5.7 方案 A）；bit9 显示**即将注入的波形** |
| 观测口径 | 复用既有 `FOC_CURRENT_LOOP_VOLTAGE_BASE_SOURCE` 语义，**不新增配置项**；通道输出即将注入的电压分量（V） |
| 特殊 phase | 注入在 COGGING_CALIB / REINIT 期间自动不生效，接受 |
| 频率精度 | 消费方使用 `freq_act`（实际生效频率），量化误差不进入 R/L 计算 |
| 辨识接入 | **本计划不接入辨识**；辨识是独立过程，由该过程操作注入工具 |
| 声学回报 | 与常规注入**共用同一查表三角函数**（阶段 4 蜂鸣器级；基波生成方式一致）；音乐为独立路线，本轮不做；**鸣叫码表暂不需要** |
| 阶段顺序 | `1 注入 → 2 解调 → 4 声学回报 → 3 参数辨识 R/L`（音频回报更易实机验证；示波器采样率不足以观测注入波形，R/L 对照条件受限） |
| 验证途径 | **C：不加临时代码**——由阶段 2 解调流程驱动注入（注入为被动工具，自身不决定"何时注入"） |
| 非法输入处理（优化轮） | **源头限幅/掩码/编译期约束替代"拒绝并上报"**：频率限幅到 `[f_环/N_max, f_环/N_min]`、幅值取幅 + 编译期上限、轴按编译期掩码收敛（NaN/非正一并入边界）；删除 `status`/`STATUS_*`/`Configure` 返回值/`ACTIVE_NONE` 与全部 `return 0` 分支，`freq_act` 为唯一口径 |
| ISR 快线（优化轮） | 配置期缓存派生量（`phase_inc_rad`、解调窗口/归一化系数、LPF 系数、延迟补偿旋转量），ISR 仅"推进 + 单次条件回卷 + 单位正弦生成 + 轴叠加 + 同拍解调累加"：无浮点除法、无变长循环、无合法性判定；单位正弦复用 L3 通用查表 `FOC_MathLut_SinCos` |
| 功能宏收敛（优化轮） | 注入与解调是同一功能的"施加"与"观测"两面，**不可拆分**：统一由 `FOC_INJECTION_ENABLE` 单宏裁剪，解调在同一 `FOC_ControlInjectionStep`（阶段 4b）内同拍完成；不设独立解调宏、独立执行阶段与专用 getter。`FOC_INJECTION_MODE` 与轴掩码是**能力集合裁剪**（有意义，保留） |
| 注入速率（优化轮） | **锚定电流环率**：`Step` 不接收 `dt`（唯一调用点恒定传 `FOC_CURRENT_LOOP_DT_SEC`；`f_act = f_环/N` 本以电流环率为基准）⇒ 相位增量有界成为不变量 |
| 指针校验（优化轮） | 模块内不设空指针检查（状态指针为 `motor` 内嵌地址，构造上非 NULL）；`.clinerules` 规则同步修订为"只在指针**可能为 NULL** 时检查" |

### 9.1 注入模块的定位（定性）

注入模块 = **其他模块的工具**：它提供"生成指定频率/幅值/轴的注入分量并叠加到 dq 电压"的能力，以及配套的解调能力；**不包含策略**（不知道也不决定为什么注入）。调用方负责：配置频率/幅值/轴、启停时机、消费解调结果。这一定位决定了：

- 接口为被动形态（`Configure` / `SetEnable` / `Step` / `Reset` / `GetActiveFrequencyHz`），无协议入口、无内部策略状态机；
- 阶段 2 的解调器同属工具层，与注入成对使用；
- 未来 HFI 位置观测、参数辨识、声学回报都是它的**调用方**，彼此独立、互不侵入。
